# Security policy

Please do not open a public issue for a suspected vulnerability.

Until a dedicated security mailbox is published, use the private security
advisory feature on the downstream GitHub mirror:

https://github.com/thystra/maintenance_tracker/security/advisories/new

Include the affected version, reproduction steps, impact, and any proposed
mitigation. Do not include real receipt images, trip locations, credentials, or
other personal data in a report.

The GitHub mirror is a security-intake exception only. Forgejo remains the
authoritative source, CI, and release repository.
